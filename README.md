# 1-oji_Uzduotis

Faile helper.h yra įtraukiami naudojami libraries, sutrumpinimai ir struktūros.
Faile functions.h yra aprašomos visos naudojamos funkcijos.

v0.2.cpp programa yra sukurta v0.1(vector).cpp programos pagrindu.

Programa atlieka pas pačias funkcijas kaip ir v0.1(vector).cpp, tačiau taip pat leidžia skaityti duomenis iš failo, įrašyti duomenis į output.txt failą, parodo laiką, kurį užtruko, bei leidžia rikiuoti atsakymus pagal pasirinktą argumentą (vardą, pavardę, vidurkį, medianą).
